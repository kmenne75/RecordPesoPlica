PESO & PLICA - PWA v4

Questa versione usa IndexedDB come archivio operativo persistente e non richiede il collegamento a una cartella ad ogni apertura.

Backup:
- sezione Dati > Esegui backup JSON
- la PWA mostra data/ora dell'ultimo backup
- dopo 7 giorni segnala che è consigliato un nuovo backup
- Ripristina backup JSON consente il recupero dei dati
- Esporta CSV crea una copia leggibile in Excel

GitHub Pages:
Caricare TUTTI i file nella root del repository, poi Settings > Pages > Deploy from a branch > main > /(root).
Dopo l'aggiornamento della precedente versione, su Android può essere utile rimuovere il vecchio collegamento/PWA e cancellare i dati del sito SOLO se non contengono dati reali non ancora esportati.
